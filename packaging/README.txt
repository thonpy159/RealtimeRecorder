リアルタイムレコーダー Windows x64 軽量配布版

1. ZIPを、書き込みできるフォルダ（ドキュメント等）へすべて展開します。
2. RealtimeRecorder.exe をダブルクリックします。Pythonのインストールは不要です。
3. マイクと相手の再生先を確認して「文字起こしを開始」を押します。

exeだけを別の場所へ移動しないでください。_internal と models が必要です。
ショートカットをデスクトップに作成して使えます。通常起動で黒いコンソールは表示しません。
Program Files等の書き込み制限のある場所への配置は避けてください。

日本語モデルReazonSpeech INT8とSilero VADを同梱しています。
軽量化のため比較用のSenseVoice・Whisper・Kotobaは含めていません。
認識精度を落とす追加圧縮は行っていません。録音・外部送信は行いません。
設定config.jsonは最初から同梱しています。アプリを終了してから、このファイルの値を
メモ帳などで変更し、UTF-8で保存して起動し直してください。dictionaryの不要な項目は削除できます。
動作ログlogsは初回起動時にexeと同じフォルダへ作成します。
文字起こしは保存ボタンからMarkdown形式で保存できます。

動作確認用の --verify-package は同梱の公開テスト音声を認識して自動終了します。
マイク録音は開始しません。結果は logs/package-check.json へ保存します。

第三者のソフトウェア・モデルの情報は THIRD_PARTY.txt と LICENSES を参照してください。
本配布版はコード署名を行っていません。
